Implement the K-means Clustering Algorithm in Python. Your code does not need to include all of the same features as Scikit-Learn, but the features that it does provide should match the KMeans object. The Scikit-Learn documentation will help you understand the important details. Here is what you must implement:

  • Constructor that takes n_clusters, random_state, and max_iter as parameters
  • fit function
  • predict function
  • fit_predict function
  • score function
  • cluster_centers_ variable
  • labels_ variable
  • inertia_ variable
  • n_iter_ variable

I suggest that you use Numpy as the basis for all of your data processing. Your input X and output y should be Numpy arrays. You are welcome to use Scikit-Learn to generate test data but you may not wrap an existing machine learning algorithm in any way.

Once you are satisfied that your K-means implementation works, test it on your Image Compression Project by substituting your own model for Scikit-Learn.

Write your module so that other people can import and use your KMeans object. In the main portion of your code, demonstrate that your code works by generating a few 2D blobs of data, clustering them, and displaying the results in a graph.
