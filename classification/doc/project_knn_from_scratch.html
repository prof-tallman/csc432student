Implement the K-Nearest Neighbors Classification algorithm from scratch in Python. You are encouraged to use Pandas and Numpy, but not any ML modules that do the work for you. Your code does not need to include all of the same features as Scikit-Learn, but the features that it provides should match the KNeighborsClassifier object. Here is what you must implement:

  • Constructor that takes n_neighbors and metric. If you are looking for a little bit of extra credit, you can figure out how to implement 'distance' weighting. You must include three possible metrics: 'euclidean' (default), 'manhattan', and 'cosine'. Pass the metrics as strings or as callable functions.
  • fit function (double-check the documentation for the correct return value!)
  • kneighbors function
  • predict function
  • score function
  • classes_ variable
  • n_features_in_ variable
  • feature_names_in_ variable (works when X is a DataFrame but not for Numpy Arrays).
  • n_samples_fit_ variable

I suggest that you use Numpy as the basis for all of your data processing. Your input X and output y should be either Pandas DataFrames or Numpy Arrays. You are welcome to use Scikit-Learn to generate test data, but you may not wrap an existing machine learning algorithm in any way.

Write your module so that other people can import and use your KNN object. In the main portion of your code, demonstrate that your code works by generating a few 2D blobs of data, with each blob being a different class. Randomly generate a new data point and use your KNN model to classify it. Then, display the results in a graph.
